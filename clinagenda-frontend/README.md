# ClinAgenda — frontend

The Vue 3 frontend of ClinAgenda, built with Vuetify, Pinia, TypeScript and Vite. See the [root README](../README.md) for what the project is, the architecture and how to run it together with the API.

```bash
yarn          # install the dependencies
yarn dev      # dev server with hot reload, on http://localhost:3000
yarn build    # type-check and build for production
yarn lint     # lint and fix
```

The API address comes from `VITE_BASE_HOST`, set in `.env.development`.
